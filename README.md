# Minecraft Client Mod: Blockfront Client

Blockfront Client is a client-side Minecraft mod for Fabric 1.21.1 that adds a configurable HUD for server connection status and player coordinates. Open its settings panel from the title screen or with the Right Shift key, then customize which details appear, the accent color, and the HUD layout.

## Install

1. Install Minecraft Java Edition 1.21.1 with Fabric Loader 0.16.0 or newer.
2. Install Fabric API for Minecraft 1.21.1.
3. Build the mod with `./gradlew build`, or obtain the built mod JAR.
4. Place the JAR in your Minecraft `mods` folder and launch the Fabric installation.

## Use

1. Select **Ender Client** on the title screen, or press **Right Shift** when no screen is open.
2. Toggle connection status and coordinates, and cycle through the available accent colors and HUD layouts.
3. Return to the game. Enabled details appear at the upper-left while in a world and while the HUD is visible.
4. Settings are saved automatically to `config/ender-client.properties`.
